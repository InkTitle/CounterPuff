CounterPuff — GoDaddy Windows Plesk upload checklist
====================================================

This is a Node.js app (Next.js). It is not PHP and not static HTML.

Upload the project folder (without node_modules, .next, .git, .env).

Required on the server
- Node.js enabled in Plesk for the domain
- Startup file: server.js
- PostgreSQL database URL (not phpMyAdmin MySQL)

Plesk environment variables
- DATABASE_URL
- AUTH_SECRET
- APP_URL=https://your-domain.com
- NODE_ENV=production
- ADMIN_BOOTSTRAP_EMAIL
- ADMIN_BOOTSTRAP_PASSWORD

Then run
  npm install          (Plesk: NPM Install)
  npm run build
  npx drizzle-kit push
  node scripts/generate-pdf.mjs
  node scripts/seed.mjs

Test
  https://your-domain.com/api/health
  https://your-domain.com/login   → admin dashboard at /admin

Full steps: deploy/plesk/PLESK-WINDOWS.md
